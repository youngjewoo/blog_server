## 데이터베이스 연결 설정

DB 접속 정보는 소스 코드에 작성하지 않고 실행 환경의 환경 변수로 전달합니다.

| 환경 변수 | 설명 | 필수 여부 |
| --- | --- | --- |
| `PGHOST` | DB 서버 주소 | 필수 |
| `PGDATABASE` | 데이터베이스 이름 | 필수 |
| `PGUSER` | DB 접속 계정 | 필수 |
| `PGPASSWORD` | DB 접속 비밀번호 | 필수 |
| `PGPORT` | DB 포트 | 선택, 기본값 `5432` |

필수 값이 없거나 포트가 유효한 정수 범위(1~65535)를 벗어나면 서버 시작을 중단합니다.
`.env.example`은 설정 항목을 보여 주는 예시이며 실제 접속 정보가 아닙니다.
현재 앱은 `.env` 파일을 자동으로 읽지 않습니다. `npm run serve` 실행 전에
셸, 서비스 관리자 또는 배포 플랫폼의 비밀 값 설정에서 환경 변수를 등록해야 합니다.
`.env` 파일을 복사하는 것만으로는 설정이 적용되지 않습니다.

실제 접속 정보는 Git에 커밋하지 말고, 비밀번호를 명령 기록이나 로그에 남기지 마세요.
`.env`와 `.env.*`는 Git 추적 대상에서 제외하며 `.env.example`만 예외로 관리합니다.
